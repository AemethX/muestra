Desplegando Nginx Proxy Manager con Docker en Ubuntu Server

Escrito por Tu Nombre
• 19 Sep, 2026 • 5 min de lectura

Gestionar múltiples servicios en un solo servidor de Linux puede volverse un caos si manejamos las configuraciones de Nginx a mano. Para hacer la vida más fácil (y más chill), utilizaremos Nginx Proxy Manager (NPM), una interfaz gráfica hermosa que maneja nuestros proxys inversos y certificados SSL gratuitos mediante Let's Encrypt.

01. Preparación del Servidor

Lo primero es asegurarnos de que nuestro servidor Ubuntu esté actualizado e instalar las dependencias necesarias. Accede a tu servidor vía SSH y ejecuta:

bash 
# Actualizar la lista de paquetes y el sistema
sudo apt update && sudo apt upgrade -y

# Instalar Docker
sudo apt install docker.io docker-compose -y

# Habilitar Docker para que inicie con el sistema
sudo systemctl enable docker
sudo systemctl start docker

02. Estructura del Proyecto

Es una buena práctica mantener nuestros contenedores organizados. Vamos a crear un directorio específico para Nginx Proxy Manager y dentro de él, nuestro archivo docker-compose.yml.

bash 
mkdir -p ~/docker/npm
cd ~/docker/npm
nano docker-compose.yml

03. Configuración de Docker Compose

Pega la siguiente configuración en tu editor. Este archivo define el contenedor, los puertos que expondrá (80, 443 para tráfico web y 81 para el panel de administración), y los volúmenes para persistir la configuración.

docker-compose.yml 
version: '3.8'
services:
  app:
    image: 'jc21/nginx-proxy-manager:latest'
    restart: unless-stopped
    ports:
      - '80:80'     # HTTP Trafico Publico
      - '81:81'     # Panel de Admin
      - '443:443'   # HTTPS Trafico Publico
    volumes:
      - ./data:/data
      - ./letsencrypt:/etc/letsencrypt

Guarda el archivo (en nano: Ctrl+O, Enter, Ctrl+X) y levanta el contenedor en segundo plano ejecutando:

sudo docker-compose up -d

04. Acceso inicial

¡Listo! Nginx Proxy Manager está corriendo. Abre tu navegador web y navega a la IP de tu servidor en el puerto 81: http://TU_IP:81.

Credenciales por defecto:

  • Email: admin@example.com
  • Password: changeme

En el primer inicio de sesión, el sistema te pedirá que cambies estos datos por unos más seguros. A partir de aquí, puedes comenzar a mapear tus subdominios a tus contenedores locales usando la hermosa interfaz web.
